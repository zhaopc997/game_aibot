# game_aibot

## AI Native Game Intelligence Platform

game_aibot 是一个面向游戏玩家的新一代 AI 游戏智能平台。

目标：
从 AI 游戏攻略助手升级为具备知识理解、任务规划、工具调用和长期记忆能力的 Game AI Copilot。

## Features

- AI 游戏问答
- 攻略知识库
- RAG 检索增强
- Agent 任务规划
- Tool Calling
- 玩家长期记忆

## Architecture

```
User
 |
AI Agent Core
 |
Planner / Memory / Tools
 |
Game Knowledge
 |
Game Environment
```

## Roadmap

V1: AI Guide Platform

V2: Game AI Copilot
